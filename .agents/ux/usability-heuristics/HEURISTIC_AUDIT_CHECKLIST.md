# Heuristic Audit Checklist

## H1 — Visibility
- [ ] current state visible
- [ ] action acknowledgement immediate
- [ ] progress shown when useful
- [ ] long operations explained

## H2 — Real-world match
- [ ] user language used
- [ ] jargon minimized
- [ ] task order feels natural

## H3 — Control and freedom
- [ ] stop/cancel available
- [ ] dialogs dismissible
- [ ] recovery possible
- [ ] destructive actions controlled

## H4 — Consistency
- [ ] terminology consistent
- [ ] state behavior consistent
- [ ] platform conventions respected

## H5 — Error prevention
- [ ] invalid actions prevented
- [ ] destructive actions protected
- [ ] validation early
- [ ] duplicates controlled

## H6 — Recognition
- [ ] current selections visible
- [ ] key actions discoverable
- [ ] icons understandable
- [ ] context visible

## H7 — Efficiency
- [ ] simple default path
- [ ] expert shortcuts where useful
- [ ] frequent actions efficient
- [ ] advanced options secondary

## H8 — Minimalism
- [ ] primary task dominant
- [ ] unnecessary UI removed
- [ ] secondary controls restrained
- [ ] diagnostics separated

## H9 — Error recovery
- [ ] message understandable
- [ ] recovery action available
- [ ] raw error not primary
- [ ] safe retry exists where applicable

## H10 — Help
- [ ] common tasks self-explanatory
- [ ] advanced help available
- [ ] troubleshooting discoverable
- [ ] privacy/permissions explained
