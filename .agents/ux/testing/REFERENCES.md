# Reference guidance

These external resources inform the procedures here. Follow actual RimV requirements and current platform documentation as relevant; do not duplicate full external publications into the repository.

- Nielsen Norman Group, *Usability Testing 101*: https://www.nngroup.com/articles/usability-testing-101/ — representative participants, realistic tasks, facilitator observation, neutral questions.
- Nielsen Norman Group, *How Many Test Users in a Usability Study?*: https://www.nngroup.com/articles/how-many-test-users/ — practical qualitative sample-size guidance and exceptions; not a fixed scientific minimum.
- Nielsen Norman Group, *Success Rate: The Simplest Usability Metric*: https://www.nngroup.com/articles/success-rate-the-simplest-usability-metric/ — task-completion measurement and limitations.
- Nielsen Norman Group, *10 Usability Heuristics*: https://www.nngroup.com/articles/ten-usability-heuristics/ — complements Part 4C.1.
- W3C WAI, *Involving Users in Evaluating Web Accessibility*: https://www.w3.org/WAI/test-evaluate/involving-users/ — include real users with disabilities, alongside technical evaluation.
- W3C WAI, *WCAG-EM 2.0*: https://www.w3.org/TR/WCAG-EM/ — systematic accessibility evaluation of digital products; distinct from formative usability testing. Published July 2026.
- W3C, *WCAG 2.2*: https://www.w3.org/TR/WCAG22/ — normative web accessibility requirements where applicable.

**Do not state that usability sessions establish WCAG conformance.** Do not imply that a particular number of participants guarantees discovery of all issues.
