# Workflow — execute a RimV UX study

1. **Prepare:** Read `.aiassistance/ux/testing/STUDY_DESIGN.md`, pick a decision, target group and tested build.
2. **Write:** Fill `templates/STUDY_PLAN.md` and selected task cards; define success and assistance before sessions.
3. **Safeguard:** Use `INCLUSIVE_RESEARCH_AND_PRIVACY.md` and the approved consent/data plan. Use sanitized test fixtures.
4. **Pilot:** Test wording, app stability, capture permissions, task order and note-taking setup; revise before recruitment.
5. **Conduct:** Use `SESSION_FACILITATION.md`. Observe without coaching. Log actual behavior in coded `SESSION_NOTES.md`.
6. **Verify data:** Review note completeness; distinguish participant failure from environmental failure and missing observations.
7. **Synthesize:** Follow `.aiassistance/workflows/UX_SYNTHESIS.md`. Report exact limitations and follow-up.

**If no participants are available:** produce the study plan and optional clearly labeled expert walkthrough; stop before reporting “results.”
