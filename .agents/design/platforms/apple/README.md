# RimV Apple Platform Design

This folder defines Apple-platform UI guidance for RimV.

It complements, rather than replaces, the shared RimV design system:

- `.aiassistance/design/RIMV_DESIGN_SYSTEM.md`

Use these rules for:

- macOS
- iOS
- SwiftUI
- AppKit
- UIKit where needed

## Core principle

RimV should preserve its product identity while feeling native on Apple platforms.

Shared identity includes:

- semantic colors;
- typography hierarchy;
- spacing rhythm;
- recording/transcription states;
- AI-state semantics;
- product terminology.

Native adaptation includes:

- navigation patterns;
- menus;
- sheets;
- alerts;
- window behavior;
- keyboard interaction;
- touch behavior;
- system controls;
- accessibility behavior.

Do not reproduce Windows, Linux, or web interaction patterns on Apple platforms merely for visual consistency.
