# RimV Windows Platform Design

This folder defines Windows-specific UI and integration guidance for RimV.

Use together with:

- `.aiassistance/design/RIMV_DESIGN_SYSTEM.md`
- `.aiassistance/agents/windows-developer.md`
- `.aiassistance/agents/ui-ux-designer.md`

## Principle

RimV on Windows should preserve the same product identity and interaction semantics as other platforms while feeling native to Windows.

Shared identity includes:

- semantic colors;
- typography hierarchy;
- recording/transcription states;
- AI-state semantics;
- terminology;
- component rhythm.

Windows adaptation includes:

- Fluent interaction patterns;
- title bars;
- navigation;
- command surfaces;
- dialogs;
- keyboard behavior;
- focus visuals;
- accessibility;
- tray/notification behavior;
- installer/update conventions.

Do not imitate macOS chrome or interaction patterns on Windows.
