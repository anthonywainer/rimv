# Windows UI Review Checklist

## Visual

- [ ] RimV design system followed
- [ ] system typography used
- [ ] light/dark themes work
- [ ] high contrast remains readable
- [ ] semantic states are consistent
- [ ] icon family is consistent

## Interaction

- [ ] primary action is obvious
- [ ] start/stop capture remains discoverable
- [ ] keyboard navigation works
- [ ] focus order is logical
- [ ] visible focus is present
- [ ] dialogs are not overused
- [ ] tray/menu behavior is concise

## Scaling

- [ ] 100% scaling works
- [ ] 125% scaling works
- [ ] 150%+ scaling works
- [ ] no clipped labels
- [ ] window remains usable at minimum size

## Accessibility

- [ ] Narrator labels meaningful
- [ ] color is not the only signal
- [ ] high contrast supported
- [ ] text scaling works
- [ ] custom controls expose correct semantics

## States

- [ ] idle
- [ ] preparing/loading
- [ ] live/listening
- [ ] transcribing
- [ ] complete
- [ ] permission denied
- [ ] recoverable error
- [ ] empty state
