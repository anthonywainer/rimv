# RimV Web Accessibility Checklist

## Structure

- [ ] page has logical landmarks
- [ ] headings follow hierarchy
- [ ] interactive controls use semantic elements
- [ ] form controls have labels

## Keyboard

- [ ] all primary actions keyboard accessible
- [ ] tab order logical
- [ ] focus visible
- [ ] no focus traps
- [ ] dialog focus managed
- [ ] Escape behavior sensible where applicable

## Screen readers

- [ ] icon-only buttons have names
- [ ] recording state exposed
- [ ] progress values exposed
- [ ] error messages associated with relevant controls
- [ ] live regions used sparingly and correctly

## Visual

- [ ] sufficient contrast
- [ ] color not only state signal
- [ ] 200%+ zoom remains usable
- [ ] text not clipped
- [ ] reduced motion respected

## Forms

- [ ] errors identify affected field
- [ ] required fields understandable
- [ ] placeholders not used as sole labels
- [ ] disabled state remains understandable

## Media / recording

- [ ] microphone status visible and announced
- [ ] permission-denied state understandable
- [ ] stop recording action accessible
- [ ] live updates do not constantly steal screen-reader attention
