# RimV Linux Platform Design

This folder defines Linux desktop UI and integration guidance for RimV.

Use together with:

- `.aiassistance/design/RIMV_DESIGN_SYSTEM.md`
- `.aiassistance/agents/linux-developer.md`
- `.aiassistance/agents/ui-ux-designer.md`

## Principle

RimV should feel at home on Linux without assuming one single desktop environment.

The implementation should respect the active toolkit and desktop environment while preserving RimV's semantic identity.
